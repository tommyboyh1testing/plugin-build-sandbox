# xlayer-gas-tracker

Read-only X Layer (chain 196) gas and fee-history monitoring for OKX Agentic Wallet agents.

## Install

```
onchainos skill install xlayer-gas-tracker
```

## Usage

```
xlayer-gas-tracker current-gas
xlayer-gas-tracker fee-history --blocks 20
xlayer-gas-tracker block-height
```

See [SKILL.md](./SKILL.md) for the agent-facing contract.
